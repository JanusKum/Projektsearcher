# EINE MILLION: Treatment

Stil: Firefly Pointillism · 1080×1920 · 60 fps · 62 s · vidIQ-Stimme „Ben“

**Idee:** Ein einziger Pool aus 125.000 Lichtpunkten. Am Anfang sind sie die Sterne der Milchstraße über einem Hügel in Deutschland. Sie werden zu den Satelliten, eine Million (1 Punkt = 8 Satelliten), und am Ende gehen sie zurück an den Himmel. Der Film zeigt so wörtlich, was Astronomen befürchten: Die Sterne werden durch Satelliten ersetzt.

| Zeit | Bild |
|---|---|
| 0–6 | Nachthimmel mit Milchstraße, Hügel, wenige ziehende Satelliten (heute) |
| 6–11 | Aufstieg ins All, die Erde aus Punkten, 17.000 Satelliten auf echten Bahnen, Titel „17.000“ |
| 11–19 | Die Genehmigung: Titel „1.000.000“ |
| 20–25 | Ein Rechenzentrum-Satellit setzt sich aus Sternen zusammen (KI im All) |
| 26–31 | Die Flut: Die Milchstraße strömt in den Orbit, die Erde verschwindet in einer leuchtenden Hülle |
| 31–35 | „× 60“ |
| 33–41 | Zoom auf Deutschland: dichter Schwarm, Ring über Deutschland, „≈ 700“ |
| 42–54 | Zurück am Boden: Der Himmel voller ziehender Lichtspuren, berechnet für einen Beobachter in Deutschland |
| 54–62 | Die Punkte steigen zurück und werden wieder zur Milchstraße. „Noch gehört der Himmel den Sternen.“ |
